# Alternate Perspective Border Starts

[Nexus Mods Download](https://www.nexusmods.com/skyrimspecialedition/mods/187466)

An addon for [Alternate Perspective](https://www.nexusmods.com/skyrimspecialedition/mods/50307), featuring starts at Skyrim's four border passes.

These are similar to the mercenary and merchant starts in [New Beginnings - Alternate Perspective Extension](https://www.nexusmods.com/skyrimspecialedition/mods/57818). However the border starts from New Beginnings also give you a specific set of equipment. This mod is meant to be a more basic alternative that only puts you at the border with no new equipment.

Compatible with:

- [Across the Border - Diverse Border Gates](https://www.nexusmods.com/skyrimspecialedition/mods/159570)
- [Beyond Skyrim - Bruma](https://www.nexusmods.com/skyrimspecialedition/mods/10917)
- [Closed and Guarded Border Gates](https://www.nexusmods.com/skyrimspecialedition/mods/8335)
- [Unique Border Gates](https://www.nexusmods.com/skyrimspecialedition/mods/4819)

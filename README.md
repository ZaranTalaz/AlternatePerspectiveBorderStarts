# Alternate Perspective Border Starts

An addon for [Alternate Perspective](https://www.nexusmods.com/skyrimspecialedition/mods/50307), featuring starts at Skyrim's four border passes.

These are similar to the mercenary and merchant starts in [New Beginnings - Alternate Perspective Extension](https://www.nexusmods.com/skyrimspecialedition/mods/57818). However the border starts from New Beginnings also give you a set of equipment, while this mod is meant to be a more basic alternative where you only begin with what you picked up in Alternate Perspective's starting room.
